# Claude 101 — Claude 入门

[← 返回课程目录](../README.md) | [English](../../README.md)

> 本指南基于 Anthropic 官方课程 **[Claude 101](https://anthropic.skilljar.com/claude-101)** 的公开内容和 [Claude 官方文档](https://docs.anthropic.com/) 编写，旨在帮助中文用户快速上手 Claude。

---

## 课程简介

**Claude** 是 Anthropic 开发的 AI 助手，能够帮助你完成写作、编程、研究、分析等各种任务。本课程将从零开始，带你了解 Claude 的工作原理、核心功能和实际应用，让你能够充分发挥 Claude 的潜力。

无论你是第一次接触 AI 工具的新手，还是希望系统了解 Claude 各项功能的用户，本课程都将为你提供清晰的学习路径。

### 学习目标

完成本课程后，你将能够：

- 理解 Claude 的基本工作原理和能力边界
- 熟练使用 Claude.ai 界面进行对话交互
- 利用 Projects、Artifacts 和 Skills 功能提升工作效率
- 掌握编写高效提示词（Prompt）的核心技巧
- 将 Claude 应用到写作、编程、研究和分析等实际场景中
- 了解 Extended Thinking、Claude Code、API 等高级功能

### 前置要求

- 无需编程经验
- 一个 [Claude 账号](https://claude.ai/)（免费版即可开始学习）

## 学习建议

1. **按顺序学习**：每个单元都建立在前一单元的基础上
2. **动手实践**：阅读示例后，尝试在 [Claude.ai](https://claude.ai/) 上亲自操作
3. **迭代改进**：学习提示词技巧后，反复练习，找到最适合你的表达方式
4. **探索进阶**：完成本课程后，可以继续学习 Anthropic Academy 的其他课程
