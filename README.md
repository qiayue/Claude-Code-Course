## Course Overview

**Claude Code in Action** is a free official course by Anthropic that teaches developers how to use Claude Code — a command-line AI assistant that reads your codebase, edits files, runs commands, and integrates with your development tools.

### What You'll Learn

- Use Claude Code's core tools for file manipulation, command execution, and code analysis
- Manage context effectively using `/init`, `CLAUDE.md` files, and `@` mentions
- Control conversation flow with hotkeys and commands
- Enable Plan Mode and Thinking Mode for complex tasks
- Create custom commands for automating repetitive workflows
- Extend Claude Code with MCP servers
- Set up GitHub integration for automated PR reviews and issue handling
- Write hooks to add additional behavior into Claude Code

### Course Structure

| Module | Topics | Duration |
|--------|--------|----------|
| Module 1: Coding Assistant Fundamentals | Introduction, What is a Coding Assistant, Claude Code in Action | ~15 min |
| Module 2: Core Features & Context Management | Adding Context, Making Changes, Controlling Context, Custom Commands, MCP Servers, GitHub Integration | ~45 min |
| Module 3: Advanced Workflows | Plan Mode & Thinking Mode, Hooks, Claude Code SDK | ~30 min |

### Prerequisites

- Basic familiarity with command-line interfaces
- Access to Claude Code (requires a [Claude subscription](https://claude.com/pricing) or [Anthropic Console](https://console.anthropic.com/) account)
