## 课程概述

欢迎来到 **Claude Code 实战** 课程！

本课程由 Anthropic 官方推出，旨在帮助开发者掌握 Claude Code —— 一个运行在终端中的 AI 编程助手。它能阅读你的代码库、编辑文件、执行命令，并与你的开发工具无缝集成。

无论你是刚接触 AI 编程工具的新手，还是希望深入掌握 Claude Code 高级功能的资深开发者，本课程都将为你提供系统性的学习路径。

## 课程结构

本课程分为三个模块，共 13 个课时，从基础到高级逐步推进：

### 模块一：编程助手基础（约 15 分钟）

- 理解 AI 编程助手的核心概念
- 了解 Claude Code 的架构与工作原理
- 完成安装并进行首次交互

### 模块二：核心功能与上下文管理（约 45 分钟）

- 学习如何有效地管理上下文信息
- 掌握文件编辑和代码修改工作流
- 创建自定义命令提升效率
- 通过 MCP 协议扩展功能
- 集成 GitHub 实现自动化

### 模块三：高级工作流（约 30 分钟）

- 使用计划模式和思考模式处理复杂任务
- 编写 Hooks 实现自动化工作流
- 通过 SDK 将 Claude Code 集成到自定义工具中

## 学习目标

完成本课程后，你将能够：

1. **理解原理** — 了解 AI 编程助手如何通过工具系统与代码库交互
2. **高效使用** — 熟练使用 Claude Code 的核心工具完成日常开发任务
3. **管理上下文** — 通过 `CLAUDE.md` 和记忆系统让 Claude 深入理解你的项目
4. **自定义工作流** — 创建自定义命令和 Hooks 来自动化重复工作
5. **扩展功能** — 使用 MCP 服务器连接外部工具和数据源
6. **团队协作** — 设置 GitHub 集成实现自动化代码审查
7. **高级应用** — 使用 SDK 将 Claude Code 嵌入到你自己的工具链中

## 前置要求

开始学习之前，请确保你具备：

- **命令行基础**：熟悉基本的终端操作（`cd`、`ls`、`git` 等）
- **编程经验**：至少了解一门编程语言
- **Claude Code 访问权限**：需要以下之一
  - [Claude Pro/Team 订阅](https://claude.com/pricing)
  - [Anthropic Console](https://console.anthropic.com/) 账号（API 使用）

## 如何使用本指南

本指南每个课时对应原始课程的一个视频，内容包括：

- **核心概念**：该课时涵盖的关键知识点
- **操作步骤**：带有代码示例的实操指导
- **实用技巧**：来自实际使用经验的建议
- **关键要点**：每课时结尾的知识总结

建议按顺序学习，因为后续课时会建立在前面的知识基础之上。
