# Anthropic Academy - Multilingual Course Guide

An unofficial multilingual study guide for all courses on **[Anthropic Academy](https://anthropic.skilljar.com/)**. This project provides comprehensive course notes and learning materials translated into multiple languages to help users worldwide learn Claude AI.

> **Note**: This is a community-driven translation project. For the official courses, please visit [Anthropic Academy on Skilljar](https://anthropic.skilljar.com/).

## Available Languages

| Language | Status | Link |
|----------|--------|------|
| English | Original Courses | [Anthropic Academy](https://anthropic.skilljar.com/) |
| 简体中文 (Chinese Simplified) | Completed | [查看中文版](./zh-CN/README.md) |

## Contributing

Contributions are welcome! If you'd like to:

- **Add a new language**: Create a new directory using the language code (e.g., `ja/`, `ko/`, `es/`) and follow the structure of `zh-CN/` as a template.
- **Improve existing translations**: Submit a pull request with your suggested changes.
- **Fix errors**: Open an issue or submit a PR.
